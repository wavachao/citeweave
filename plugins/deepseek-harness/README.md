# CiteWeave for DeepSeek Harness

**Web evidence and sourced illustrations for agent answers.**

[简体中文](README.zh-CN.md) · [CiteWeave](../../README.md) · [API reference](../../docs/API.md) · [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)

CiteWeave adds the `citeweave_search` tool to DeepSeek Harness. It retrieves public webpages, describes candidate images, and selects relevant illustrations. Harness uses the returned evidence to compose answers with inline images and links to their original sources.

- Automatic web search or up to five explicit source pages.
- Visual descriptions, relevance ranking, and source attribution.
- Persistent images displayed through Harness's native Markdown renderer.
- A separate CiteWeave backend; no changes to Harness are required.

## Requirements

- DeepSeek Harness `0.2.1-rc.2` and Node.js 24 or later.
- A CiteWeave backend from the [`feature/deepseek-harness-images` branch](https://github.com/wavachao/citeweave/tree/feature/deepseek-harness-images), reachable from the Harness host.
- The backend's Linux, Python and NVIDIA GPU requirements described in the [deployment guide](../../docs/DEPLOYMENT.md).

## Installation

### Start the backend

```sh
git clone --branch feature/deepseek-harness-images https://github.com/wavachao/citeweave.git
cd citeweave
uv sync --frozen
cp .env.example .env
uv run python scripts/download_models.py
uv run python -m citeweave serve
```

The backend listens on `http://127.0.0.1:8765`. Configure an access token for network deployment. The [deployment guide](../../docs/DEPLOYMENT.md) covers containers, authentication and model installation; the [trained image ranker](../../README.md#add-the-trained-image-ranker) is optional.

### Install the plugin

From the repository root, in another terminal:

```sh
cd plugins/deepseek-harness
npm ci
dsh plugin --profile web add "$PWD"
```

The plugin loads directly as an ES module and requires no build step. For installation on another Harness host, run `npm pack`, transfer the resulting archive, and install it:

```sh
dsh plugin --profile web add /absolute/path/dsh-citeweave-0.1.0.tgz
```

### Connect Harness

Set the backend address in the environment used to launch Harness:

```sh
export CITEWEAVE_ENDPOINT=http://127.0.0.1:8765
dsh --profile web
```

If the backend requires authentication, also set `CITEWEAVE_ACCESS_TOKEN` to its workspace token. In PowerShell, use `$env:CITEWEAVE_ENDPOINT='http://127.0.0.1:8765'` and `$env:CITEWEAVE_ACCESS_TOKEN='<workspace-token>'`.

For a remote backend, use a reachable HTTPS endpoint or an SSH tunnel. Images are downloaded by the Harness host; the browser does not need direct access to CiteWeave.

## Usage

Ask a question that benefits from illustrations:

> Explain how Eratosthenes measured Earth's circumference. Include a relevant diagram and cite its source.

Harness can select `citeweave_search` from the request. The tool also accepts explicit source URLs for a focused search.

| Parameter | Type | Description |
| --- | --- | --- |
| `query` | string | Required question or search topic. |
| `urls` | string[] | Optional list of 1–5 public source pages. Omit to search the web. |
| `verify_images` | boolean | Generate visual descriptions of candidate images. Default: `true`. |
| `refresh` | boolean | Bypass the recent-evidence cache. Default: `false`. |

The final answer is generated by Harness. CiteWeave supplies the text evidence, selected images, descriptions and source URLs through [`POST /api/evidence`](../../docs/API.md#post-apievidence).

## Configuration

Environment variables provide the default connection settings. To configure the plugin directly, create `citeweave.config.yml`:

```yaml
- id: citeweave
  config:
    endpoint: http://127.0.0.1:8765
    timeoutMs: 180000
    maxImages: 3
```

```sh
dsh --profile web --patch /absolute/path/citeweave.config.yml
```

| Setting | Default | Description |
| --- | --- | --- |
| `endpoint` | `CITEWEAVE_ENDPOINT` or `http://127.0.0.1:8765` | CiteWeave service URL. |
| `accessToken` | `CITEWEAVE_ACCESS_TOKEN` or empty | Backend workspace token. |
| `timeoutMs` | `180000` | Request timeout in milliseconds. |
| `maxImages` | `3` | Maximum images per search; range: 1–8. |

Non-empty `endpoint` and `accessToken` settings take precedence over environment variables.

## Operation

Selected image bytes are imported into Harness's persistent attachment store. The tool returns local image destinations for the native Markdown renderer, keeping backend credentials out of image links. The Harness filesystem provider must expose the attachment paths; remote execution environments require the corresponding path mapping.

Images depend on source availability and relevance. When none is suitable, the tool returns text evidence without images. Individual image download failures are reported alongside the remaining evidence. A busy backend returns `409`; retry after the active request finishes.
